# LunarChat-alpha
LunarChat Alpha - это самая первая версия LunarChat. Состоит из одного чата, написан на python с фреймворком Django. Этот проект не предназначен для особых нагрузок и был создан как первый опыт 

# Характеристики
- Язык программирования: Python
- Фреймворк: Django
- БД: Sqlite
- Шифрование паролей и иных данных: SHA-256
  
# Описание
LunarChat - соц. сеть для коммуникации пользователей друг с другом. Он делится на 2 типа:
- Alpha (этот репозиторий)
- Release

Альфа версия состоит из одного общего чата, с регистрацией и авторизацией по логину-паролю. 
Переписываться можно срзау после авторизации в аккаунт.
Доступна функция на переключение простого интерфейса для старых браузеров/устройств (NT).

На данный момент для LunarChat Alpha я прекратил поддержку, и лишь делаю обновления по безопасности.

Доступ к LunarChat Alpha идёт строго через браузер.
Есть команды администратора для модерации.

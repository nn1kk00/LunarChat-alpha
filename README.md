# LunarChat Alpha
LunarChat Alpha - это самая первая версия LunarChat. Состоит из одного чата, написан на python с фреймворком Django. Этот проект не предназначен для особых нагрузок и был создан как первый опыт 

# Характеристики
- Язык программирования: Python, HTML, CSS, немного JS
- Фреймворк: Django
- БД: Sqlite
- Шифрование паролей и иных данных: SHA-256
- Стиль (CSS): Windows Aero

# Основные функции
- Команды для модерации
- Поддержка старых браузеров
- С пользователя собирает лишь айпи, логин и пароль
- Лёгкодоступность к чату
  
# Описание
LunarChat - соц. сеть для коммуникации пользователей друг с другом. Он делится на 2 типа:
- Alpha (этот репозиторий)
- Release

Был запущен 31 марта 2025 года.
Официальная дата для альфа версии 1 апреля 2025 года.

Альфа версия состоит из одного общего чата, с регистрацией и авторизацией по логину-паролю. 
Переписываться можно сразу после авторизации в аккаунт.
Доступна функция на переключение простого интерфейса для старых браузеров/устройств (NT).
LunarChat Alpha позволяет взаимодействовать с пользователями в браузерах без поддержки JS.

На данный момент для LunarChat Alpha я прекратил поддержку, и лишь делаю обновления по безопасности.

Доступ к LunarChat Alpha идёт строго через браузер.
Есть команды администратора для модерации. 

(P.S. В названиях и в коде мелькает название clydechat. Это кодовое слово для Backend)

# Настройка & запуск
1. Установите библиотеки
```pip install -r req.txt ```
3. Запускаем
```python manage.py runserver ```
- Eсли есть желание развернуть НЕ на 8000 и не на localhost, то пропишите так
```python manage.py runserver {айпи}:{порт 0-65535} ```

!! Примечание. ЕСЛИ вы изменяете файлы по типу models.py, admin.py и тп, то обязательно перед запуском выполните ```python manage.py migrate```
